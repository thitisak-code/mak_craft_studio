Frequently Asked Questions

คำถามที่พบบ่อย (FAQ)

ข้อสงสัยทั่วไปเกี่ยวกับการว่าจ้างพัฒนาซอฟต์แวร์กับเรา

ลูกค้าได้รับกรรมสิทธิ์ใน Source Code และฐานข้อมูล 100% เต็มรูปแบบเมื่อส่งมอบงานเสร็จสมบูรณ์ สามารถนำไปติดตั้งบน Server ขององค์กรเอง หรือพัฒนาต่อยอดได้อย่างอิสระโดยไม่มีสัญญาผูกมัด
เรามีระยะเวลารับประกัน Bug / Defect ฟรีหลังส่งมอบ และมีแพ็กเกจดูแลรักษาระบบ (Maintenance & SLA Support) ทั้งการอัปเดตความปลอดภัย, สำรองข้อมูล (Backup), ปรับแต่ง Performance และดูแล Server ตลอด 24/7
สามารถทำได้ครับ ทีมงานเราเชี่ยวชาญการทำ API Integration, Database Migration และการเชื่อมต่อระหว่างระบบ (เช่น ERP, Payment Gateway, Active Directory/LDAP, หรือ Line OA) เพื่อให้ระบบทำงานประสานกันอย่างไร้รอยต่อ
หลังจากได้รับรายละเอียดความต้องการ (Requirement) ทีมงานจะทำการวิเคราะห์และออกใบเสนอราคา (Quotation) พร้อมเอกสาร Scope of Work (SOW) ภายใน 1-3 วันทำการ โดยไม่มีค่าใช้จ่ายในการปรึกษาเบื้องต้น
